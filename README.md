# Sora for Mac — releases

Signed and notarized builds of the Sora Mac app, and the update feed (`appcast.xml`) the app checks for new versions.

Sora is a self-hosted personal agent team: the app connects to its owner's own Sora server. To install: download the
latest `Sora-*.zip` from [Releases](../../releases/latest), unzip it, and drag Sora to Applications. After that, Sora
updates itself (Sora → Check for Updates…).
